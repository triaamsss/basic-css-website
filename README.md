## Basic CSS Website

A responsive portofolio website styled with CSS, built for the roadmap.sh frontend project.

Project page: https://roadmap.sh/projects/portfolio-website

Live demo: https://triaamsss.github.io/basic-css-website/

## Features

- Responsive layout (mobile first) using Flexbox and media queries
- Responsive navigation bar (stacked on mobile, inline on desktop)
- Three-column info section on desktop (Projects, Work Experience, Education) that stacks on mobile
- Review cards that sit side by sode on dekstop and stack on mobile
- Consistent color scheme and typography (Google fonts: Poppins and Inter)
- Dark mode using CSS variables (following the system setting)

## How to run

No build step needed.

```bash
git clone https://github.com/triaamsss/basic-css-website.git
cd basic-css-website
```

Then open 'index.html' in your browser (or use the VS Code Live Server extension).

## Structure

```
index.html page structure
style.css all styles (variables, layout, media queries, dark mode)
```
